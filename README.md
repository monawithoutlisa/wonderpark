# Idea Wonderpark — Anonymous Public Demo

This folder is a standalone, identity-free public edition of the interactive wonderpark.

## Included

- Interactive low-poly park
- Day, sunset, night, lights, sound, and scene controls
- Five composite, anonymous concept studies with one neutral generated cover
- A small public learning archive
- Generative visual studies
- Fourteen retained photographs with neutral captions
- An abstract regional globe
- Dolly as a privacy-aware guide

## Intentionally omitted

- Personal names and portraits
- Employers, schools, clients, and collaborators
- Contact details, social accounts, and downloadable résumés
- Exact dates, metrics, awards, and application status
- Project URLs, repositories, and private reports
- Exact city history, saved-place counts, and personal routes
- Original project screenshots and identity-bearing photographs
- Session records, prompts tied to a person, and usage metadata

## Run locally

Serve this directory through a local HTTP server and open `index.html`. The page loads only `park-content.js` from this folder and image assets under `assets/`.
